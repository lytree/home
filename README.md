# Home

一个基于 **Vue 3 + Vite + TypeScript** 的个人主页项目，提供时间展示、一言与常用网站导航等功能。整体使用 Vue Vapor 模式 + JSX 编写，最大化首屏渲染性能。

> 原 fork 自 `imsyy/home`，已通过 Vapor 重写。

## 功能特性

- 载入动画与欢迎文案

- 实时时间与日期展示

- Hitokoto 一言

- 常用网站导航链接（Swiper 轮播）

- 移动端适配

- 自定义光标动画

- 壁纸背景与切换
